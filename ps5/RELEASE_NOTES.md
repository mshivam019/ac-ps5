# Animal Crossing for PS5 — v1.0.0

## Changes

- Native PS5 build with 4K / 60 FPS target and an optional 1080p profile.
- Corrected blank-screen rendering and startup portability issues.
- Fixed oversized NPC slots so station characters can spawn correctly.
- Fixed save-storage exhaustion by limiting the graphics diagnostic log.
- Added DualSense replacements for identified GameCube prompt textures, including the separate notice-board button faces.
- Removed the large Backspace, OK, Cursor and Space labels beside the keyboard icons; input functions and keyboard-mode indicators are retained.
- Added sourced leaf icon and matching selection/launch backgrounds.
- Added a catalog-format title ZIP alongside Windows/Linux installer packages.

## Requirements

- A compatible jailbroken PS5 and native-title installation workflow.
- Your own Animal Crossing USA GAFE01 revision 0 ISO/GCM, prepared separately.
- Optional HD texture pack, installed separately. No game data or community pack is included.

## Installation

- PPSA99660.zip contains the native title folder at the ZIP root for catalog/store installation.
- Windows/Linux ZIPs contain the same PS5 application and platform-specific installer helpers.
- Back up saves, save normally and close the title before updating. Existing saves and private game data are preserved by the installer.
